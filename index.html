Install the preview

Updating? Quit the running app before replacing it in Applications. You may need to grant Along Accessibility access again.

  1. Download and open the DMG.

    Download Along 0.7.0 for Apple Silicon.

  2. Move Along into Applications.

    Drag the app into Applications and eject the disk image.

  3. Open the installed app.

    Open Along from Applications. If macOS blocks it, follow the first-launch note below.

  4. Grant Accessibility access.

    In System Settings → Privacy & Security → Accessibility, enable Along so it can arrange your windows. Return to Along and click Check Again.

  5. Press Control + Option + P.

    Start the row. Press the same shortcut to stop and restore.

About this preview

This preview is not notarized by Apple. macOS may require approval through System Settings → Privacy & Security → Open Anyway.

Before you installThe practical details of an early preview.
  • Apple Silicon only.

    Requires macOS 13 or later.

  • One display, current Space.

    Each session uses one display and the current Space. Switching Spaces stops the row and attempts restoration.

  • App restrictions still apply.

    Some apps impose window-size or position restrictions.

  • Normal quits can restore.

    Force-quitting cannot restore window positions.

  • Fresh-install compatibility testing is still pending.

    This is a preview release.
